The generated documentation is a single self-contained HTML file, so sharing it is as simple as moving a file — no build step, server, or Bruno installation required on the reader's side.

## Deployment Options

Once generated, you can:

1. **Open locally**: View the HTML file in any browser
2. **Static hosting**: Deploy to GitHub Pages, Netlify, Vercel, or any static host
3. **Share directly**: Send the HTML file to team members or API consumers
4. **Documentation portal**: Add to your developer portal or docs site

<Tip>
  The spec changed? Regenerate the file from Collection Settings and replace the deployed copy — the [generation steps](/html-docs/generate) take under a minute.
</Tip>
