Mock servers are coming to Bruno in an upcoming release.

Mock servers let you simulate API responses without a live backend — so you can build against an API before it exists, develop the frontend and backend in parallel, and test edge cases that are hard to reproduce against real services.

<Info>
  This section is a preview of what's ahead. Documentation will land here alongside the release — in the meantime, keep an eye on the [changelog](https://www.usebruno.com/changelog) and [roadmap](https://www.usebruno.com/roadmap).
</Info>
