Open the folder in the app, or run it with the CLI:

<Tabs>
  <Tab title="Bruno app">
    1. Click the **+** button in the top-left corner and select **Import Collection**.
    2. Choose **Bruno Collection**, then browse to the output folder.
    3. Click **Import**.

    See [Import Collections](/get-started/import-export-data/import-collections) for more detail.
  </Tab>
  <Tab title="Bruno CLI">
    ```bash
    cd <output-folder>
    bru run
    ```

    To use an environment, pass its name with `--env`:

    ```bash
    bru run --env <environment-name>
    ```

    See [Run a Collection](/bru-cli/runCollection) for more options.
  </Tab>
</Tabs>
