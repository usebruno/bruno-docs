<Note>
  Starting from Bruno v4.0.0, secret manager configuration has moved from **Collection > Secrets** to **Environment > External Secrets**.
</Note>

<Info>
  **Fetching and storage**

  - **Fetch Secrets** (or the first request that needs them) loads values into memory for that environment only.
  - Secret values are **never saved on your machine**. Bruno only keeps provider settings and the `op://` secret references.
  - Closing Bruno or the collection clears the cache. Reopen the app and Bruno fetches secrets again when you need them.
</Info>

1. Open your collection environment and go to **External Secrets**.
2. Select **1Password**, or choose an account you already added in Preferences. Use **Add new account** if you need to create one.
3. Click **Save and continue**.
4. Add rows under **Secrets**:
   - **Name** - the alias used in Bruno, for example `username` (referenced as `{{username}}`)
   - **Secret Reference** - a 1Password secret reference in the form `op://vault/item/field`, for example `op://BrunoTestVault/login/username`
5. Click **Save**.
6. Click **Fetch Secrets** in the top-right.

After a successful fetch, values appear under **Value** for the session (you can use **View all values** / **Clear all values** as needed). Only the **Name** and **Secret Reference** are persisted in the environment file (`.bru` or `.yml`). Resolved values are never written to disk.

Use the three-dots menu to:

- **Edit account** to change account details
- **Remove secret manager** to remove 1Password from this environment
