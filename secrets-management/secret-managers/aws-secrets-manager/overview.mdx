[AWS Secrets Manager](https://aws.amazon.com/secrets-manager/) is a secure and scalable service designed to store and retrieve sensitive information such as API keys, database credentials, and other secrets. 

Bruno allows you to easily integrate with AWS Secrets Manager and securely access secrets during test execution without exposing them in test scripts or environment variables.

<Info>
  **How Bruno keeps AWS secrets safe**

  - Secret values are **never saved on your machine**. Bruno only keeps provider settings and secret names.
  - Secrets are fetched **when you need them** and kept in memory for that environment for the rest of the session. Later requests reuse them; a manual refresh pulls fresh values.
  - Closing Bruno or the collection clears those values. Reopen the app and Bruno fetches secrets again on demand. Interpolation in requests keeps working as usual.
</Info>
