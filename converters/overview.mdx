`@usebruno/converters` is a standalone npm package that converts Postman collections and environments, Insomnia collections, OpenAPI specifications, and WSDL files into Bruno collections from your own code.

## Installation

<Info>
  Requires Node.js 18 or later. The latest LTS release is recommended.
</Info>

Install the converters together with `@usebruno/filestore`, which the guides use to write the converted collection to disk as a folder Bruno can open.

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @usebruno/converters @usebruno/filestore
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add @usebruno/converters @usebruno/filestore
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add @usebruno/converters @usebruno/filestore
    ```
  </Tab>
</Tabs>

Both packages are published on npm: [@usebruno/converters](https://www.npmjs.com/package/@usebruno/converters) and [@usebruno/filestore](https://www.npmjs.com/package/@usebruno/filestore).
