`@usebruno/converters` is a standalone npm package that converts Postman collections and environments, Insomnia collections, OpenAPI specifications, and WSDL files into Bruno collections from your own code.

## Installation

<Info>
  Requires Node.js 18 or later. The latest LTS release is recommended.
</Info>

Install the converters together with `@usebruno/io`, which writes the converted collection to disk as an OpenCollection YAML folder Bruno can open.

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @usebruno/converters @usebruno/io
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add @usebruno/converters @usebruno/io
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add @usebruno/converters @usebruno/io
    ```
  </Tab>
</Tabs>

Both packages are published on npm: [@usebruno/converters](https://www.npmjs.com/package/@usebruno/converters) and [@usebruno/io](https://www.npmjs.com/package/@usebruno/io).

## Typical flow

1. Convert with a function from `@usebruno/converters`.
2. Save with `writeCollection(collection, outputDir)` from `@usebruno/io`.

```javascript
import { postmanToBruno } from '@usebruno/converters';
import { writeCollection } from '@usebruno/io';

const { collection, issues } = await postmanToBruno(input);
await writeCollection(collection, outputDir);
```

`writeCollection` always writes OpenCollection YAML (`opencollection.yml`, `folder.yml`, one `.yml` per request, and `environments/<name>.yml`).
