Convert an Insomnia export into a Bruno collection folder you can open in the app or run with the CLI.

Start by exporting the collection from Insomnia. Both the JSON export from Insomnia v4 and the YAML export from Insomnia v5 work. See [Import collections](/get-started/import-export-data/import-collections) for the export steps.

## Convert the collection

<ConvertersSetup />

### 1. Read the arguments

Import the converter, `writeCollection` from `@usebruno/io`, and Node's file helpers. Take the paths from the command line and print a usage line if any are missing.

```javascript
import { insomniaToBruno } from '@usebruno/converters';
import { writeCollection } from '@usebruno/io';
import { readFile } from 'fs/promises';

const [inputFile, outputDir] = process.argv.slice(2);
if (!inputFile || !outputDir) {
  console.error('Usage: node convert.mjs <insomnia-export.json> <output-folder>');
  process.exit(1);
}
```

### 2. Convert and write

`insomniaToBruno` returns the Bruno collection. Pass it to `writeCollection` to save an OpenCollection YAML folder. See the [API Reference](./api-reference#insomniatobruno) for the full signature.

```javascript
const raw = await readFile(inputFile, 'utf8');
const insomniaCollection = inputFile.endsWith('.yaml') || inputFile.endsWith('.yml')
  ? raw
  : JSON.parse(raw);

const collection = insomniaToBruno(insomniaCollection);
await writeCollection(collection, outputDir);

console.log(`Collection written to ${outputDir}`);
```

### 3. Run the script

<CodeGroup>
```bash convert.mjs
node convert.mjs <insomnia-export.json> <output-folder>
```

```bash convert.js
node convert.js <insomnia-export.json> <output-folder>
```
</CodeGroup>

Where:

- `<insomnia-export.json>`: The collection exported from Insomnia (JSON or YAML)
- `<output-folder>`: The folder to create the Bruno collection in. It is created if it does not exist

The output folder looks like this:

```text
my-collection/
├── opencollection.yml
├── environments/
│   └── Base Environment.yml
├── Users/
│   ├── folder.yml
│   ├── List users.yml
│   └── Create user.yml
└── Ping.yml
```

```javascript convert.js
// Converts an Insomnia export into a Bruno collection folder.
// Usage: node convert.js <insomnia-export.json> <output-folder>

const { insomniaToBruno } = require('@usebruno/converters');
const { writeCollection } = require('@usebruno/io');
const { readFile } = require('fs/promises');

const [inputFile, outputDir] = process.argv.slice(2);
if (!inputFile || !outputDir) {
  console.error('Usage: node convert.js <insomnia-export.json> <output-folder>');
  process.exit(1);
}

async function main() {
  const raw = await readFile(inputFile, 'utf8');
  const insomniaCollection = inputFile.endsWith('.yaml') || inputFile.endsWith('.yml')
    ? raw
    : JSON.parse(raw);

  const collection = insomniaToBruno(insomniaCollection);
  await writeCollection(collection, outputDir);

  console.log(`Collection written to ${outputDir}`);
}

main();
```
