Convert a WSDL file into a Bruno collection of SOAP requests you can open in the app or run with the CLI.

<Tip>
  You do not need a script to import a WSDL file. The Bruno app imports one through **Import Collection** (see [Import collections](/get-started/import-export-data/import-collections#7-wsdl-web-services-description-language)), and the CLI does it in one command: `bru import wsdl --source <service.wsdl> --output <output-folder>` (see [bru import](/bru-cli/import/overview)). Use the script below when you want to process the collection in your own code.
</Tip>

## Convert the WSDL

<ConvertersSetup />

### 1. Read the arguments

Import the converter, `writeCollection` from `@usebruno/io`, and Node's file helpers. Take the paths from the command line and print a usage line if any are missing.

```javascript
import { wsdlToBruno } from '@usebruno/converters';
import { writeCollection } from '@usebruno/io';
import { readFile } from 'fs/promises';

const [inputFile, outputDir] = process.argv.slice(2);
if (!inputFile || !outputDir) {
  console.error('Usage: node convert.mjs <service.wsdl> <output-folder>');
  process.exit(1);
}
```

### 2. Convert and write

`wsdlToBruno` resolves to the Bruno collection. Pass it to `writeCollection` to save an OpenCollection YAML folder. See the [API Reference](./api-reference#wsdltobruno) for the full signature.

```javascript
const wsdlContent = await readFile(inputFile, 'utf8');
const collection = await wsdlToBruno(wsdlContent);
await writeCollection(collection, outputDir);

console.log(`Collection written to ${outputDir}`);
```

### 3. Run the script

<CodeGroup>
```bash convert.mjs
node convert.mjs <service.wsdl> <output-folder>
```

```bash convert.js
node convert.js <service.wsdl> <output-folder>
```
</CodeGroup>

Where:

- `<service.wsdl>`: The WSDL file
- `<output-folder>`: The folder to create the Bruno collection in. It is created if it does not exist

The output folder looks like this:

```text
my-collection/
├── opencollection.yml
└── Calculator/
    ├── Add.yml
    └── Subtract.yml
```

### Full script

<CodeGroup>
```javascript convert.mjs
// Converts a WSDL file into a Bruno collection folder.
// Usage: node convert.mjs <service.wsdl> <output-folder>

import { wsdlToBruno } from '@usebruno/converters';
import { writeCollection } from '@usebruno/io';
import { readFile } from 'fs/promises';

const [inputFile, outputDir] = process.argv.slice(2);
if (!inputFile || !outputDir) {
  console.error('Usage: node convert.mjs <service.wsdl> <output-folder>');
  process.exit(1);
}

const wsdlContent = await readFile(inputFile, 'utf8');
const collection = await wsdlToBruno(wsdlContent);
await writeCollection(collection, outputDir);

console.log(`Collection written to ${outputDir}`);
```

```javascript convert.js
// Converts a WSDL file into a Bruno collection folder.
// Usage: node convert.js <service.wsdl> <output-folder>

const { wsdlToBruno } = require('@usebruno/converters');
const { writeCollection } = require('@usebruno/io');
const { readFile } = require('fs/promises');

const [inputFile, outputDir] = process.argv.slice(2);
if (!inputFile || !outputDir) {
  console.error('Usage: node convert.js <service.wsdl> <output-folder>');
  process.exit(1);
}

async function main() {
  const wsdlContent = await readFile(inputFile, 'utf8');
  const collection = await wsdlToBruno(wsdlContent);
  await writeCollection(collection, outputDir);

  console.log(`Collection written to ${outputDir}`);
}

main();
```
</CodeGroup>
