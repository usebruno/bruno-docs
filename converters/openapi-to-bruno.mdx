Convert an OpenAPI specification into a Bruno collection folder you can open in the app or run with the CLI.

<Tip>
  The CLI can do this in one command: `bru import openapi --source <openapi.yaml> --output <output-folder>`. See [bru import](/bru-cli/import/overview). Use the script below when you want to process the collection in your own code.
</Tip>

## Convert the specification

<ConvertersSetup />

### 1. Read the arguments

Import the converter, `writeCollection` from `@usebruno/io`, and Node's file helpers. Take the paths from the command line and print a usage line if any are missing.

```javascript
import { openApiToBruno } from '@usebruno/converters';
import { writeCollection } from '@usebruno/io';
import { readFile } from 'fs/promises';

const [inputFile, outputDir] = process.argv.slice(2);
if (!inputFile || !outputDir) {
  console.error('Usage: node convert.mjs <openapi.yaml> <output-folder>');
  process.exit(1);
}
```

### 2. Convert and write

`openApiToBruno` accepts the specification as JSON or YAML and returns the Bruno collection. Pass `{ groupBy: 'path' }` as a second argument to group folders by path instead of tag. See the [API Reference](./api-reference#openapitobruno) for the full signature.

```javascript
const openApiSpec = await readFile(inputFile, 'utf8');
const collection = openApiToBruno(openApiSpec);
await writeCollection(collection, outputDir);

console.log(`Collection written to ${outputDir}`);
```

### 3. Run the script

<CodeGroup>
```bash convert.mjs
node convert.mjs <openapi.yaml> <output-folder>
```

```bash convert.js
node convert.js <openapi.yaml> <output-folder>
```
</CodeGroup>

Where:

- `<openapi.yaml>`: The OpenAPI or Swagger specification (JSON or YAML)
- `<output-folder>`: The folder to create the Bruno collection in. It is created if it does not exist

The output folder looks like this:

```text
my-collection/
├── opencollection.yml
├── environments/
│   └── Environment 1.yml
└── pets/
    ├── folder.yml
    ├── List pets.yml
    └── Create pet.yml
```

### Full script

<CodeGroup>
```javascript convert.mjs
// Converts an OpenAPI specification into a Bruno collection folder.
// Usage: node convert.mjs <openapi.yaml> <output-folder>

import { openApiToBruno } from '@usebruno/converters';
import { writeCollection } from '@usebruno/io';
import { readFile } from 'fs/promises';

const [inputFile, outputDir] = process.argv.slice(2);
if (!inputFile || !outputDir) {
  console.error('Usage: node convert.mjs <openapi.yaml> <output-folder>');
  process.exit(1);
}

const openApiSpec = await readFile(inputFile, 'utf8');
const collection = openApiToBruno(openApiSpec);
await writeCollection(collection, outputDir);

console.log(`Collection written to ${outputDir}`);
```

```javascript convert.js
// Converts an OpenAPI specification into a Bruno collection folder.
// Usage: node convert.js <openapi.yaml> <output-folder>

const { openApiToBruno } = require('@usebruno/converters');
const { writeCollection } = require('@usebruno/io');
const { readFile } = require('fs/promises');

const [inputFile, outputDir] = process.argv.slice(2);
if (!inputFile || !outputDir) {
  console.error('Usage: node convert.js <openapi.yaml> <output-folder>');
  process.exit(1);
}

async function main() {
  const openApiSpec = await readFile(inputFile, 'utf8');
  const collection = openApiToBruno(openApiSpec);
  await writeCollection(collection, outputDir);

  console.log(`Collection written to ${outputDir}`);
}

main();
```
</CodeGroup>
