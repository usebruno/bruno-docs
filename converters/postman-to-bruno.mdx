Convert a Postman collection and environment into a Bruno collection folder you can open in the app or run with the CLI.

<Tip>
  Prefer the CLI for bulk migrations? From Bruno 4.4.0 onward you can run `bru import postman -s <collection.json> -o <dir>` without writing a script. See [bru import](/bru-cli/import/overview#importing-postman-collections). Use the script below when you want to convert in your own Node code.
</Tip>

Start by exporting the collection from Postman in the Collection v2.1 format and, if you use one, the environment. See [Postman migration](/get-started/import-export-data/postman-migration) for where to find the export buttons.

## Convert the collection and environment

<ConvertersSetup />

### 1. Read the arguments

Import the converter, `writeCollection` from `@usebruno/io`, and Node's file helpers. Take the paths from the command line and print a usage line if any are missing.

```javascript
import { postmanToBruno, postmanToBrunoEnvironment } from '@usebruno/converters';
import { writeCollection } from '@usebruno/io';
import { readFile } from 'fs/promises';

const [collectionFile, outputDir, environmentFile] = process.argv.slice(2);
if (!collectionFile || !outputDir) {
  console.error('Usage: node convert.mjs <postman-collection.json> <output-folder> [postman-environment.json]');
  process.exit(1);
}

const readJson = async (file) => JSON.parse(await readFile(file, 'utf8'));
```

### 2. Convert

`postmanToBruno` resolves to the Bruno collection and a list of `issues` it could not convert cleanly. If an environment file was given, convert it and add it to the collection so it is written with the rest. See the [API Reference](./api-reference#postmantobruno) for the full signature.

```javascript
const { collection, issues } = await postmanToBruno(await readJson(collectionFile));

if (environmentFile) {
  collection.environments.push(postmanToBrunoEnvironment(await readJson(environmentFile)));
}
```

### 3. Write the collection folder

`writeCollection` writes a complete OpenCollection directory Bruno can open: `opencollection.yml`, `folder.yml` per folder, one `.yml` per request (including examples), and `environments/<name>.yml`.

```javascript
await writeCollection(collection, outputDir);

console.log(`Collection written to ${outputDir}`);

for (const issue of issues) {
  console.warn(`${issue.severity}: ${issue.path}: ${issue.message}`);
}
```

### 4. Run the script

Run the script with Node.js, passing the paths as arguments.

<CodeGroup>
```bash convert.mjs
node convert.mjs <postman-collection.json> <output-folder> [postman-environment.json]
```

```bash convert.js
node convert.js <postman-collection.json> <output-folder> [postman-environment.json]
```
</CodeGroup>

Where:

- `<postman-collection.json>`: The collection exported from Postman
- `<output-folder>`: The folder to create the Bruno collection in. It is created if it does not exist
- `[postman-environment.json]`: Optional. An environment exported from Postman

The output folder looks like this:

```text
my-collection/
├── opencollection.yml
├── environments/
│   └── Dev.yml
├── Users/
│   ├── folder.yml
│   ├── List users.yml
│   └── Create user.yml
└── Ping.yml
```

One folder per Postman folder, one YAML file per request, and the environment under `environments`.

### Full script

The complete script, ready to copy. `convert.mjs` is an ES module with top-level `await`. `convert.js` is the same script as CommonJS, with the steps inside an async `main` function.

<CodeGroup>
```javascript convert.mjs
// Converts a Postman collection, and optionally an environment, into a Bruno collection folder.
// Usage: node convert.mjs <postman-collection.json> <output-folder> [postman-environment.json]

import { postmanToBruno, postmanToBrunoEnvironment } from '@usebruno/converters';
import { writeCollection } from '@usebruno/io';
import { readFile } from 'fs/promises';

const [collectionFile, outputDir, environmentFile] = process.argv.slice(2);
if (!collectionFile || !outputDir) {
  console.error('Usage: node convert.mjs <postman-collection.json> <output-folder> [postman-environment.json]');
  process.exit(1);
}

const readJson = async (file) => JSON.parse(await readFile(file, 'utf8'));

const { collection, issues } = await postmanToBruno(await readJson(collectionFile));

if (environmentFile) {
  collection.environments.push(postmanToBrunoEnvironment(await readJson(environmentFile)));
}

await writeCollection(collection, outputDir);

console.log(`Collection written to ${outputDir}`);

for (const issue of issues) {
  console.warn(`${issue.severity}: ${issue.path}: ${issue.message}`);
}
```

```javascript convert.js
// Converts a Postman collection, and optionally an environment, into a Bruno collection folder.
// Usage: node convert.js <postman-collection.json> <output-folder> [postman-environment.json]

const { postmanToBruno, postmanToBrunoEnvironment } = require('@usebruno/converters');
const { writeCollection } = require('@usebruno/io');
const { readFile } = require('fs/promises');

const [collectionFile, outputDir, environmentFile] = process.argv.slice(2);
if (!collectionFile || !outputDir) {
  console.error('Usage: node convert.js <postman-collection.json> <output-folder> [postman-environment.json]');
  process.exit(1);
}

const readJson = async (file) => JSON.parse(await readFile(file, 'utf8'));

async function main() {
  const { collection, issues } = await postmanToBruno(await readJson(collectionFile));

  if (environmentFile) {
    collection.environments.push(postmanToBrunoEnvironment(await readJson(environmentFile)));
  }

  await writeCollection(collection, outputDir);

  console.log(`Collection written to ${outputDir}`);

  for (const issue of issues) {
    console.warn(`${issue.severity}: ${issue.path}: ${issue.message}`);
  }
}

main();
```
</CodeGroup>
