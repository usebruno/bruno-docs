`bru import` takes the source type first, then options that choose the source, the output location, and related settings:

```bash
bru import <type> [options]
```

`<type>` is `postman`, `openapi`, or `wsdl`. To view the options available in your installed version:

```bash
bru import postman -h
bru import openapi -h
bru import wsdl -h
```

The other commands document their options on their own pages: [bru run](/bru-cli/run/options) and [bru docs](/bru-cli/docs/options).

## Options

| Option                             | Details                                                                                                                                                             |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-s`, `--source [string]`          | Path or URL to the source (Postman Collection v2.1 JSON, OpenAPI YAML or JSON, or WSDL)                                                                             |
| `-o`, `--output [string]`          | Output **directory** for a collection on disk (folder import)                                                                                                       |
| `-f`, `--output-file [string]`     | Output **file** path for a single Bruno collection JSON export (OpenAPI)                                                                                            |
| `-n`, `--collection-name [string]` | Name for the imported collection                                                                                                                                    |
| `-e`, `--env [string]`             | **Postman only:** path to a Postman environment JSON export                                                                                                         |
| `--preserve-scripts`               | **Postman only:** keep Postman scripts as written instead of translating `pm.*` to `bru.*`                                                                          |
| `--collection-format [string]`     | **OpenAPI folder import only:** `bru` (classic `.bru` files) or `opencollection` ([OpenCollection YAML](/opencollection-yaml/overview)). Default: `opencollection`. |
| `--insecure`                       | Skip TLS verification when `--source` is an `https://` URL                                                                                                          |
| `-g`, `--group-by [string]`        | OpenAPI only: group requests by `tags` or `path` (default: `tags`)                                                                                                  |
| `--request-name-source [string]`   | OpenAPI only: how requests are named: `summary` (default), `operationId`, `description`, or `path`                                                                  |
| `--auth-placement [string]`        | OpenAPI only: where to place auth: `request` (default) or `collection`                                                                                              |

Use `--output` to write a collection to a directory, or `--output-file` to write a single collection JSON export (OpenAPI). Postman imports always write [OpenCollection YAML](/opencollection-yaml/overview). For OpenAPI directory imports, `--collection-format` chooses between OpenCollection YAML (the default) and classic `.bru` files.

<Info>
  `bru import postman` requires **Bruno CLI 4.4.0** or higher.
</Info>
