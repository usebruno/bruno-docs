`bru import` takes the specification type first, then options that choose the source, the output location, and the on-disk layout of the collection:

```bash
bru import <type> [options]
```

`<type>` is `openapi`, `wsdl`, or `postman`. To view the options available in your installed version:

```bash
bru import openapi -h
bru import wsdl -h
bru import postman -h
```

The other commands document their options on their own pages: [bru run](/bru-cli/run/options) and [bru docs](/bru-cli/docs/options).

## Options

| Option                             | Details                                                                                                                                                             |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-s`, `--source [string]`          | Path or URL to the source (OpenAPI YAML or JSON, WSDL, or Postman collection JSON)                                                                                  |
| `-o`, `--output [string]`          | Output **directory** for a collection on disk (folder import)                                                                                                       |
| `-f`, `--output-file [string]`     | Output **file** path for a single Bruno collection JSON export                                                                                                      |
| `-n`, `--collection-name [string]` | Name for the imported collection                                                                                                                                    |
| `--collection-format [string]`     | **OpenAPI and WSDL folder imports only** (not supported for `postman`): `bru` (classic `.bru` files) or `opencollection` ([OpenCollection YAML](/opencollection-yaml/overview)). Default: `opencollection`. |
| `--insecure`                       | Skip TLS verification when `--source` is an `https://` URL                                                                                                          |
| `-g`, `--group-by [string]`        | OpenAPI only: group requests by `tags` or `path` (default: `tags`)                                                                                                  |
| `-e`, `--environment [string...]`  | Postman only: one or more Postman environment exports (file or URL) to convert alongside the collection. Repeat the flag for each file.                              |
| `--preserve-scripts`               | Postman only: keep Postman scripts verbatim instead of translating `pm.*` calls to `bru.*` (default: `false`)                                                       |

Use `--output` to write a collection to a directory, or `--output-file` to write a single collection JSON export. For directory imports, `--collection-format` chooses between OpenCollection YAML (the default) and classic `.bru` files.
