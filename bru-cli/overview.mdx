With Bruno CLI, you can run your API collections with ease using simple command line commands.

This makes it easier to test your APIs in different environments, automate your testing process, and integrate your API tests with your continuous integration and deployment workflows.

New to the CLI? Start with the [Quick Start](/bru-cli/quick-start) walkthrough.

<Warning>
  **v3.0.0 Breaking Change** Starting from Bruno CLI v3.0.0, the default runtime
  mode has changed from **Developer Mode** to **Safe Mode** for improved
  security. If you need to use Developer Mode features (external npm packages,
  filesystem access), you must explicitly pass the `--sandbox=developer` flag
  when running collections.
</Warning>

## Key Features of Bruno CLI:

**1. Execute API Requests & Collections**: Run individual API requests or entire collections directly from the command line with [`bru run`](/bru-cli/run/overview).

**2. Generate Test Reports**: Easily create reports in multiple formats, including JSON, JUnit, and HTML, to analyze and share test results.

**3. Import API Specifications**: Turn an OpenAPI or WSDL specification into a ready-to-run collection with [`bru import`](/bru-cli/import/overview).

**4. Generate API Documentation**: Produce standalone HTML documentation from a collection with [`bru docs`](/bru-cli/docs/overview).

**5. CI/CD Integration**: Effortlessly integrate with CI/CD pipelines for automated testing and validation.
